# 记单词网页应用开发计划

## 项目结构
- 在现有项目基础上创建记单词应用，保留现有AI新闻功能
- 创建新的HTML文件 `vocabulary.html` 作为记单词应用主页面
- 修改 `style.css` 添加记单词应用样式
- 创建 `vocabulary.js` 实现记单词应用功能

## 功能模块

### 1. 导航切换
- 在顶部导航栏添加"记单词"和"AI新闻"切换按钮
- 实现单页应用切换效果

### 2. 记单词页面
- **输入表单**：包含单词、词组/例句、标签输入框
- **标签系统**：支持自定义标签，自动补全
- **提交功能**：保存到本地存储，显示成功提示

### 3. 单词本页面
- **按标签分类**：显示所有未掌握的单词，按标签分组
- **单词卡片**：展示单词、词组/例句、标签
- **记住功能**：勾选"记住啦"复选框，将单词移到单词库
- **搜索功能**：支持按单词或标签搜索

### 4. 单词库页面
- **已掌握单词**：显示所有已标记为掌握的单词
- **按标签分类**：同样按标签分组展示
- **查看详情**：可查看完整单词信息

### 5. 数据存储
- 使用 localStorage 持久化存储单词数据
- 数据结构：
  ```javascript
  {
    id: "唯一ID",
    word: "单词",
    phrase: "词组/例句",
    tags: ["标签1", "标签2"],
    mastered: false, // 是否掌握
    createdAt: "创建时间"
  }
  ```

## 技术实现
- HTML5 + CSS3 + JavaScript (ES6+)
- 响应式设计，适配移动端和桌面端
- 本地存储，无需后端
- 模块化代码，便于维护和扩展

## 实现步骤
1. 创建 `vocabulary.html` 主页面结构
2. 修改 `style.css` 添加记单词应用样式
3. 创建 `vocabulary.js` 实现核心功能
4. 集成到现有项目，实现导航切换
5. 测试所有功能，确保正常运行
